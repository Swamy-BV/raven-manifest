# Raven manifest

Start here to fetch the Raven platform sources for NXP FRDM-IMX95.
The Yocto build integrates Linux, Cortex-M7 PX4/NuttX and the boot components.

[Setup and build instructions](https://github.com/Swamy-BV/meta-raven/tree/develop#build) | [Demo gallery](https://swamy-bv.github.io/raven-demos/)

[![Six-car tracking on NXP i.MX95](https://raw.githubusercontent.com/Swamy-BV/raven-demos/main/images/six-car-tracking.png)](https://swamy-bv.github.io/raven-demos/)

The demo uses i.MX95 Linux for NPU vision, tracking and guidance, with actual
M7 PX4 controlling an AirSim aircraft. Physical flight remains unqualified.
